# Product Dashboard

A modern React TypeScript application for browsing and managing products. Built with Vite, featuring a responsive design with search, filtering, and pagination capabilities.

## Features

- **Product Search**: Search products by title
- **Category Filtering**: Filter products by category
- **Price Sorting**: Sort products by price (ascending/descending)
- **Pagination**: Navigate through product listings
- **Product Details**: View detailed product information in a modal
- **Responsive Design**: Optimized for desktop and mobile devices

## Technologies Used

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Usage

- Use the search bar to find products by name
- Select a category from the filter dropdown
- Choose sorting order (price low to high or high to low)
- Click on any product card to view details in a modal
- Navigate through pages using the pagination controls

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run ESLint
- `npm run preview` - Preview production build
- `npm run typecheck` - Run TypeScript type checking
